# Явные разрешения и понятный журнал изменений

## Принцип

Важные автоматические действия обвязки **выключены по умолчанию**. Значение
параметра в БД, наличие старого бэкапа или запуск панели не считаются разрешением
переписать входящий, Host или другой сервис.

Есть три разных вида действий:

1. **Явный параметр окружения.** Например, заданный `XUI_PORT` переопределяет
   порт панели; пустой/отсутствующий сохраняет поле БД. `XUI_ADMIN_PASSWORD`
   означает явное применение пароля, а не разрешение менять его случайно.
2. **Действие с отдельным разрешением.** Например, перемещение порта входящего
   возможно только при `XUI_REWRITE_INBOUNDS=true`.
3. **Явная команда пользователя.** `apply`, `install`, `restore`, `restart`
   выполняют запрошенную операцию, включая копирование обвязки, настройку её
   systemd-hooks и перезапуск панели. Это не команды только для просмотра.

Политика реализована в `fork-policy.sh` и используется одинаково при запуске
панели, применении обвязки, установке и фоновом наблюдении БД.

## Посмотреть разрешения без применения

```bash
x-ui-fork policy
```

Команда читает активное окружение и показывает только известные флаги. Она не
меняет БД, файлы конфигурации и службы, не печатает пароли/токены. Чтение `.env`
по-прежнему использует shell source: файл должен быть доверенным и доступным
только администратору. Не загружайте чужой файл окружения.

## Матрица разрешений

Все перечисленные флаги по умолчанию `false`:

| Флаг | Что разрешает | Без разрешения |
|---|---|---|
| `XUI_AUTO_DB_APPLY` | Фоновое применение окружения при изменениях БД | Наблюдатель не запускается; уже вызванный worker выходит до изменений |
| `XUI_AUTO_CERTS` | Запрос/перевыпуск сертификатов обвязкой | Используются существующие файлы; новые запросы CA не запускаются |
| `XUI_AUTO_CERT_DOMAINS` | Поиск доменов всех входящих/Hosts для ACME | Импортированный бэкап не запускает массовые попытки выпуска; нужен также AUTO_CERTS |
| `XUI_REWRITE_INBOUNDS` | Перенос портов для HAProxy, смена listen/локального Reality target, metrics и удаление externalProxy | Эти поля БД сохраняются |
| `XUI_SYNC_INBOUND_CERTS` | Замена отсутствующих TLS-файлов входящих сертификатом панели/fallback | Сертификаты входящих настраиваются вручную |
| `XUI_HOSTS_SYNC` | Автосборка Hosts из входящих в legacy-режиме | Все ручные поля Hosts сохраняются |
| `XUI_HOSTS_INHERIT_TLS` | Живое копирование только явных fingerprint/ALPN в существующие Hosts | Поля не копируются; AUTO_DB_APPLY/HOSTS_SYNC для включения не нужны |
| `XUI_TUNE_NETWORK` | Изменение sysctl параметров TCP ядра | Сеть ОС не перенастраивается |
| `XUI_CLEANUP_ORPHANS` | Старое завершение предполагаемых осиротевших Xray/MTProto процессов по имени | Никакого pkill/killall; при конфликте порта требуется диагностика |
| `XUI_DB_MAINTENANCE` | Переключение БД на WAL и удаление дубликатов settings | Формат журналирования и дубликаты не изменяются |
| `XUI_MANAGE_SYSTEM_NGINX` | Остановка и отключение системной nginx.service при установке/apply | Существующий системный Nginx не трогается; файлы сайтов не удаляются даже с разрешением |
| `XUI_CERTBOT_STOP_WEB_SERVER` | Краткая остановка известного владельца HTTP/80 для ACME | Стандартный веб-сервер не останавливается; нужны webroot/DNS-01 или ручное решение |
| `XUI_REPAIR_XRAY_TEMPLATE` | Замена повреждённого xrayTemplateConfig копией из файла при настройке логов | Ошибка показывается; сохранённый шаблон не заменяется |
| `XUI_SELFSTEAL_ALLOW_FALLBACK_CERT` | Legacy-подстановка другого/самоподписанного сертификата заглушки | Отсутствующий сертификат вызывает ошибку, а не смену TLS-идентичности |

**Не включайте всё сразу.** Особенно опасны завершение процессов по имени,
массовая перезапись входящих/Hosts и ремонт шаблона: сначала резервная копия и
понимание конкретного изменения. Для обычного ручного управления они не нужны.

ALPN и fingerprint не угадываются по Vision/gRPC, а минимальная версия
REALITY-клиента больше не принудительно выставляется ни при каком разрешении.
Уже сохранённые значения автоматически не очищаются — это тоже изменение,
которое должен выбрать администратор.

**Не путать:** `XUI_HOSTS_INHERIT_TLS=true` — [наследование двух полей](HOSTS-INHERIT.md)
после сохранения входящего без перезапуска Xray. Работает и в REALITY SelfSteal,
не меняет адрес/порт/SNI/security и не включает полную legacy-синхронизацию.

## Отдельные службы и публичные порты

- `XUI_HAPROXY_ENABLE=true` явно разрешает настройку HAProxy. Если его TCP/443
  конфликтует с существующим входящим и перезапись входящих не разрешена,
  операция заканчивается ошибкой без изменения порта входящего.
- Отсутствующий `XUI_HAPROXY_ENABLE` не останавливает чужой HAProxy. Явное
  `false` означает запрос отключить его; это видно в журнале.
- `XUI_SELFSTEAL_ENABLE` теперь по умолчанию `false`. Существующие серверные
  `.env` с явным `true` не изменяются обновлением.
- Для публичной legacy-заглушки нужно явное `XUI_SELFSTEAL_PUBLIC=true`.
  Без него она слушает только локальный HTTPS, не публичные 80/443.
- В режиме `reality` Nginx локальный, а внешний порт принадлежит REALITY.
  Он не переносится автоматически. Unix-сокет не требует миграции всех узлов.
- `x-ui-fork restart` запрашивает перезапуск x-ui, а не всех активных прокси на
  сервере. В его ExecStartPre могут выполняться отдельно разрешённые действия;
  они видны в журнале. Отдельные перезапуски HAProxy/заглушки CLI не дублирует.

Выключенный флаг обычно означает **не применять** автоматическую настройку,
а не откатить историю. Отключение sysctl-автоматики не возвращает прежние
значения ядра; отключение авто-ACME не удаляет сертификаты и не отменяет уже
существующий certbot.timer. Откат выполняется отдельно и осознанно.

## Как читать вывод

```text
[POLICY] XUI_REWRITE_INBOUNDS=false (без автоматических изменений)
[SKIP] Изменение портов, listen, Reality target ... — требуется явное XUI_REWRITE_INBOUNDS=true
[KEEP] setting=webPort; причина: уже соответствует заданной конфигурации; значение скрыто
[CHANGE] setting=webDomain; причина: проверенная конфигурация TLS панели; значение скрыто
[SKIP] setting=webBasePath; причина: параметр не задан; сохранено значение БД; значение скрыто
[SUMMARY] Параметры settings: изменено=1, сохранено=1, пропущено=1; предупреждений=0
```

Счётчик относится к обычным полям `settings`, а не ко всем SQL-операциям или
системным службам. Пакетные разрешённые действия имеют отдельные сообщения.
Повторное применение уже совпадающего значения не записывает его в БД заново.
Значения не печатаются: даже путь панели или URL может содержать секрет.

`[ALLOW]` означает **разрешено**, но не доказывает успех. `[WARN]`/`[ERROR]`
требуют проверки. Ни `[DONE]`, ни успешная локальная проверка HTTPS не доказывают,
что реальный клиент подключился, маршрутизация работает и нет фильтрации сети.

## Обновление уже работающего сервера

1. Сохраните SSH-доступ, текущую БД и активный `.env`.
2. В каталоге проекта получите обновление, посмотрите эффективные разрешения,
   затем установите **всю** обвязку:

   ```bash
   x-ui-fork backup
   git pull --ff-only
   x-ui-fork policy
   x-ui-fork apply
   ```

3. Не заменяйте серверное окружение целиком новым `.env.example`. Иначе можно
   потерять свои домены и включённый SelfSteal. Новые выключенные разрешения
   можно вообще не добавлять: отсутствие означает `false`.
4. Сначала нужен `apply`, а не только `git pull` и restart: runtime должен
   получить новый общий `fork-policy.sh`. Неполная ручная копия скриптов
   отклоняется с ошибкой вместо применения непроверенных значений.
5. По умолчанию apply отключит **управляемый форком** наблюдатель
   `x-ui-fork-db-apply.path`, чтобы изменения панели не запускали неявную
   перенастройку. Нужна автоматика — явно задайте AUTO_DB_APPLY и повторите apply.
6. Для работающего REALITY SelfSteal сохраните свои текущие MODE, ENABLE,
   DOMAIN, локальный порт и явный список HTTP-backend. Firefox/h2 и другие
   проверенные значения в Hosts менять ради обновления не требуется.

## Что всё ещё выполняется намеренно

- На совершенно пустой БД допускается начальная генерация недостающих порта и
  пути панели, а при отсутствии TLS — bootstrap-сертификат панели. Существующие
  поля не заменяются этой генерацией. Ключи защищаются правами доступа.
- Неудачная TLS-миграция сохраняет домен и пути. Для подписки без доступного TLS
  сохраняется защита от случайной публикации по HTTP: она отключается с явным
  сообщением, если не выбран осознанный HTTP-режим. См. [CERTIFICATES.md](CERTIFICATES.md).
- Установка/apply обновляют собственные runtime-файлы, шаблоны и unit-файлы
  форка; это явная операция развёртывания. Код самой установленной версии панели
  может иметь собственную автоматику, которую эта обвязка не отключает.
- Переменные окружения с конкретными значениями продолжают переопределять свои
  поля БД. Это относится и к старым значениям, оставленным в активном `.env`.
  Пустое значение не означает восстановление состояния до импорта бэкапа.
